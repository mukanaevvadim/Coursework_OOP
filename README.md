
# [Курсовая работа "Ip Detector"](https://github.com/netology-code/pyapi-diplom-basic/blob/ip_detector/README.md)

## Исполнитель:
Студент группы PDARZ-TRF-162 Муканаев Вадим

## Задание: 
1. Получить ip адреса с помощью сервиса [ipify](https://api.ipify.org/?format=json);
2. Далее получить данные о местоположении через сервис [ipinfo](https://ipinfo.io/188.242.138.63/geo);
3. Сохранить эту информацию в json файл;
4. Загрузить json файл на Яндекс.Диск через [REST API Диска](https://yandex.ru/dev/disk/rest).

## Как установить:
1. Установить зависимости из **requirements.txt**;
2. Создать файл **.env** на основе **.env.example** и вставить свой токен из полигона Яндекс.Диска в переменную **TOKEN**;
3. Запустите программу
